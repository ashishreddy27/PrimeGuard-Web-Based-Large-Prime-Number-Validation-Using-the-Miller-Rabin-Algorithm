THE MATH

How Miller–Rabin works

Miller–Rabin is a probabilistic primality test. It quickly rejects composite numbers by checking whether chosen bases behave as they should for primes.

n − 1=2s × d→ad mod n
  1. Handle small numbers and even values.
  2. Write n − 1 as 2ˢ × d, where d is odd.
  3. For each base a, compute aᵈ mod n.
  4. Square repeatedly and check for 1 or n − 1.
  5. A failed round proves composite; passing all rounds means probable prime.
THE PROJECT

About PrimeGuard

PrimeGuard is an educational number-theory workspace built to make primality testing transparent. It combines large-integer input, configurable Miller–Rabin rounds, dataset testing, and a live computation trace in one responsive interface.
